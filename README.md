# CommentPick

Pick a fair giveaway winner from pasted comments. Duplicate filtering, animated draw, and a public winner log — free, no signup.

## Features
- Duplicate and empty-comment filtering with live entry count
- Animated draw with suspense countdown
- Winner history log with timestamps and pool sizes
